# So_long 🕹️

**So_long** is a project that involves creating a simple 2D game using the MiniLibX library. The goal is to understand and implement basic game mechanics, graphics rendering, and user input handling.

## Features

- **2D Graphics:** Render a 2D game map using MiniLibX.
- **Player Movement:** Handle player movement and interactions.
- **Collectibles and Exit:** Implement game objectives like collecting items and reaching the exit.
- **Basic Enemy AI:** Add basic enemy behavior to challenge the player.

## Technologies Used

- **C:** The game is implemented in C.
- **MiniLibX:** A simple X-Window (X11) programming API in C, designed for students.

## Installation

1. **Clone this repository:**
    ```bash
    git clone https://github.com/damiandania/So_long.git
    ```

2. **Navigate to the project directory:**
    ```bash
    cd So_long
    ```

3. **Build the project:**
    ```bash
    make
    ```
